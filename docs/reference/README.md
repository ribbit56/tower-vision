# Mood board

Drop 3 to 8 reference images here before Milestone 1 (PNG or JPG). Claude Code
looks at these before any visual work.

Good things to include:

- Warm storybook illustrations with soft, muted, earthy colors
- A picture-book cross-section of a tower, lighthouse, or windmill (the
  dollhouse/cutaway view is the important part)
- Photos of real hand-built stone or timber-frame towers, for course lines and
  material texture
- A sky palette you love at dusk or dawn
- Any texture you like for the paper grain

Add a line below for each image saying what you like about it, for example:
"lighthouse.jpg: the soft mortar lines and warm interior glow, not the
lantern room shape."
